# Vidéo de démo, 3 minutes · narration française, sous-titres anglais

Règle : chaque image de la démo vient d'un run réel (replays générés depuis les dossiers de preuves). Rien n'est mis en scène
dans la démo. La seule scène narrative est la scène 0 (le choc), construite sur le replay de la boutique fictive Maison Verde et
une coupure au noir : aucun chiffre, aucun site réel, aucune promesse ; elle dit ce qui arrive, pas ce que l'outil a fait.
Le fondateur lit la colonne « Voix (FR) » ; la colonne « Sous-titre (EN) » est incrustée. Les durées font 2 min 58.

## Fabrication

- Replays : `npm run repair-replay -- examples/repair-maison-verde/repair-2026-10-28-11-18 F14`, idem F05 ; F06 dans le run 11-35 ; recherche : `node bench/make-replay.js examples/dbir-2025` ; retour à zéro : `examples/back-to-zero/replay.html` ; vrai site : `examples/real-site/`.
- Scène 0 : les deux premières scènes du replay F14 (le site qui tourne), puis une coupure au noir montée au montage (ffmpeg), carte texte noire. Aucune image inventée, aucun chiffre.
- Durées imposées aux scènes avec `--scenes=` pour coller à la voix.
- Voix : enregistrement du fondateur (WAV), une prise par ligne ; sous-titres incrustés par ffmpeg ; chaîne `video/make-video.cjs`.
- À faire le 2 ou 3 novembre, sur la version finale, sur le mot du gérant.
