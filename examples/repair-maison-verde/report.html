Recommended fix: Remove sensitive Disallow entries (/admin, /backup/, /.env, /export/) from robots.txt. Do not rely on robots.txt for access control — robots.txt is only a crawler instruction, not a security control. Enforce server-side authentication and access controls on those paths, and if the goal is only to prevent indexing, use Robots META tags / X-Robots-Tag (noindex) instead of listing the paths in robots.txt.

  • tenable.com use Robots META tags instead of entries in the robots.txt file
