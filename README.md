# Mission Zero

**Give it a goal. Let it discover the path. Demand proof.**

Mission Zero takes an objective, constraints and a budget. It has no plan and no tool list. It forms hypotheses, builds the tools it needs, runs experiments, observes the results, and changes its approach when it fails. Every step leaves verifiable evidence.
